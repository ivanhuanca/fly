# Mosca de escritorio

Aplicacion para Windows que anima `sprite_fly.png` en una ventana transparente, siempre visible, que no recibe clics ni toma el foco.

- Inicia la mosca con doble clic en `iniciar_mosca.bat`.
- Pulsa `Ctrl+Alt+F8` para pausar o reanudarla.
- Pulsa `Ctrl+Alt+F9` para cerrarla.
- Requiere Python para Windows con Tkinter. Instala Pillow con `python -m pip install -r requirements.txt`.
